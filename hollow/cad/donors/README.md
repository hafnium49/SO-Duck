# SO-101 donor solids

These seven STEP files are unmodified copies from [TheRobotStudio/SO-ARM100](https://github.com/TheRobotStudio/SO-ARM100), directory `STEP/SO101/`, at commit `141aea7bcac2744d92998e30268c413202a56f96`. They are licensed under Apache-2.0; the licence text is in [`LICENSES/SO-ARM100_APACHE-2.0.txt`](../../../LICENSES/SO-ARM100_APACHE-2.0.txt).

| File | Used for |
| --- | --- |
| `Under_arm_SO101.step` | Round ends and servo seats of the two links |
| `Base_motor_holder_SO101.step` | Servo holder of the neck socket mount |
| `Motor_holder_SO101_Wrist.step` | Reference only: the tests measure how the stock holder fits its servo |
| `Upper_arm_SO101.step`, `Rotation_Pitch_SO101.step`, `Motor_holder_SO101_Base.step`, `Wrist_Roll_Pitch_SO101.step` | Stock parts of the arm, for clearance checks and the model |

`SHA256SUMS` lists their checksums. Each imports in CadQuery as one valid closed solid.
